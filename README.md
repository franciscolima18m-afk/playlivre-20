# PlayLivre V2

## Novidades
- Player de áudio real com `just_audio`
- Play/Pause
- Próxima/Anterior
- Barra de progresso
- Shuffle
- Repeat
- Busca
- Favoritos em memória
- Playlists básicas

## Executar
```bash
flutter pub get
flutter run
```
